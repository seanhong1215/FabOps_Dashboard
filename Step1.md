# 12. Portfolio Highlights

## Problem: Factories cannot monitor equipment status and production efficiency in real time.

## Result

- Real-time monitoring latency < 1 second

- Improved equipment monitoring efficiency

- Simulate OEE analysis process

- Establish an anomaly early warning system
